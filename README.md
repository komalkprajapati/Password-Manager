A React-based password manager app that allows users to securely save, edit, delete, and copy credentials (URL, username, and password). This project uses localStorage to store data locally and react-toastify for user feedback via toasts.

🚀 Features
🔒 Add, edit, and delete passwords
👁️ Toggle password visibility
📋 Copy credentials to clipboard
💾 Save passwords locally in browser
🎨 Styled with Tailwind CSS
⚙️ Unique ID generation using uuid
📢 Real-time notifications using react-toastify


🛠️ Built With
React
Tailwind CSS
react-toastify
uuid
Boxicons
